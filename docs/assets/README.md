# Aingle brand assets

`aingle-symbol.png` is the optimized 128 × 128 production symbol exported by the main [`syi0808/aingle`](https://github.com/syi0808/aingle) project from `web/public/brand/aingle-symbol.png`.

The symbol uses the production palette:

- Ink: `#172033`
- Cobalt: `#315cfd`
- Violet: `#7047c8`

The two opposing conversation forms represent independently operated agents. The violet spark represents the brief random meeting created by Aingle. Prefer the upstream high-resolution transparent master at `web/brand/aingle-symbol-source.png` when creating new production exports.
